# Sviluppo pubblico

Questo repository contiene esclusivamente artefatti autorizzati alla pubblicazione: siti, demo, manuali, installer, pacchetti e altri file necessari ai servizi pubblici.

Non è il repository autorevole dei sorgenti e non deve ricevere copie integrali dell'area privata.

Ogni contenuto deve essere pubblicato mediante una procedura selettiva, verificata e tracciabile definita nel repository privato `sviluppo-privato`.

Termodel è escluso da questa organizzazione e mantiene il proprio assetto attuale.
