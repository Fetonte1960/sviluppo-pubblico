04

Avvia ChatGPT

Bootstrap iniziale come in Tiralinee MCP.

Collega ChatGPT al server tramite OAuth; quindi avvia la chat con le istruzioni di base. Il token segreto non deve essere incollato nella chat.

Collegamento ChatGPT con OAuth
https://mcp-postgree.onrender.com/mcp
  1. Prima premi Genera token e attiva demo, poi Copia accanto al token.
  2. Nella configurazione MCP di ChatGPT inserisci l'URL qui sopra e scegli OAuth come autenticazione.
  3. Quando si apre la pagina protetta mcp-postgree.onrender.com, incolla lì il token e premi Autorizza il collegamento.
  4. Torna in ChatGPT, richiama CommandToMCPPostgree("Init") e verifica i due schemi demo.

Importante: il token viene consegnato soltanto al nostro server nella pagina di autorizzazione, mai a ChatGPT come testo del messaggio.

In ChatGPT seleziona OAuth. La schermata protetta del server chiederà il token del gestionale; aprire una chat non installa automaticamente il connettore.
